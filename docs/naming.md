# Naming shortlist

Status: **open**, Pablo decides before the public deploy. Until then the codename is `carrera-web`.

Availability was checked on 2026-11-27 with a DNS lookup only. "No DNS record" does **not** prove a
domain is free (it can be registered but unused). Confirm at a registrar (e.g. dominios.es, Porkbun)
and search the OEPM trademark database before committing. Every one-word candidate I tried
(arranque, brujula, trampolin, primerpaso, despega, cantera, ancla, rumbo) already resolves on both
.es and .com, so the shortlist uses two-word names.

| #   | Name                | Idea                                                         | .es           | .com          |
| --- | ------------------- | ------------------------------------------------------------ | ------------- | ------------- |
| 1   | **Primera Jornada** | Your first working day; warm, concrete, easy to say.         | no DNS record | no DNS record |
| 2   | **Ruta Junior**     | A route for juniors; says what it is, good for SEO.          | no DNS record | no DNS record |
| 3   | **Primer Rumbo**    | First heading; compass image fits "which industry fits me?". | no DNS record | no DNS record |
| 4   | **Mapa de Carrera** | Literal: the map of industries (pillar 1). Less brandable.   | no DNS record | no DNS record |
| 5   | **Paso a Uno**      | Playful "step one"; short, but meaning is less obvious.      | no DNS record | no DNS record |

Discarded: `brujulajoven.com`, `puertaabierta.es/.com`, `arrancatucarrera.com` (taken).

## Recommendation

**Primera Jornada** or **Ruta Junior**. Tests worth doing: say it aloud to three classmates, check the
TikTok/Instagram/LinkedIn handles, and make sure the name still works when the site covers industries
beyond consulting.

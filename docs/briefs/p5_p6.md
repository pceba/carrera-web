## P5: `/practica` interview practice with your own key

Owned: `src/app/(public)/practica/`, `src/components/practice/`, `src/lib/byok/`,
`src/lib/practice/`, `e2e/practica.spec.ts`, `docs/handover/p5-byok.md`.

- AGENTS rule 3: the key is the user's, stays in the browser, **never reaches our server**
  (no API route, no server action, no logging). Calls go straight from the browser with `fetch`.
  Storage: `sessionStorage` by default, opt-in "Recordar en este navegador" for `localStorage`
  (try/catch), a "Borrar clave" button. Explain costs: the provider bills the user.
- Providers (one small adapter each, streaming if simple): **Google Gemini** (free tier, default
  suggestion for students), **Anthropic** (`anthropic-dangerous-direct-browser-access: true`
  header; default model `claude-haiku-5-5`), **OpenAI**. Model field editable. Clear error
  messages for 401/429/CORS. If the site sets a CSP `connect-src`, add exactly these three API
  hosts and say so in the handover.
- Modes: (1) caso de consultoría (interviewer leads, one question at a time, asks for structure,
  maths, synthesis), (2) técnicas de finanzas IB/PE (accounting, valuation, LBO basics), (3)
  entrevista de comportamiento (STAR). System prompts as versioned files in `src/lib/practice/`,
  Spanish, Spain context, no invented firm facts or pay. Session ends with feedback against a
  short rubric shown as cards. Chat UI with P3 primitives; transcript stays in memory only,
  with "Descargar transcripción" (.txt).
- Without a key the page shows a demo transcript and a 3-step "cómo conseguir tu clave" per
  provider (links to the official consoles).
- e2e with a mocked `fetch` (route interception): enter key, run two turns, get feedback;
  key absent from any request to our own origin.
